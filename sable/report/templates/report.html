    Limitations

    No changes have been applied by this report. Fix selections and the interactive view are predictions, including recommendations that require manual action. They do not execute commands.

    An absence of paths does not prove the host is secure.{% if r.no_writes.status == "not_run" %} With filesystem verification marked not_run, this scan has no verified no-writes result.{% elif r.no_writes.status == "failed" %} Filesystem verification failed. Review the unexpected changes listed in the certificate section.{% endif %}

    This is a screening aid, not proof of exploitation or a substitute for a manual security assessment. Missing evidence may hide weaknesses. Credential discovery alone does not establish credential reuse.

    Path confidence multiplies step likelihoods and assumes step independence. Goal scoring counts shared edges once; larger graphs use a fixed-seed Monte Carlo estimate. Marginal risk sums path confidences and is not a probability of compromise.

    High confidence starts at {{ planning.bands.high_min if planning else 0.6 }}; Medium starts at {{ planning.bands.medium_min if planning else 0.3 }}; lower values are Low. Paths are limited to {{ planning.path_cutoff if planning else 6 }} edges. Robust planning can consider only unknown edges represented in the supplied graph.

    The exact solver checks at most 15 candidate fixes. No-write verification, rollback execution, and post-fix rescans are separate checks; this report does not perform them.
